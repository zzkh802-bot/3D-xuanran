# 课程球面知识地图需求文档

## 1. 项目目标

将任意课程的“课程—章节—小节—知识点”结构展示在可交互的三维球面上，让用户能从整体到局部逐级查看和编辑课程内容，并通过通用 JSON 配置复用结果。

## 2. 核心功能

- [x] 展示高等数学上、高等数学下、线性代数、概率论与数理统计四门示例课程。
- [x] 支持点击课程进入单球查看，并可返回课程总览。
- [x] 支持拖拽旋转和缩放球体。
- [x] 根据缩放距离自动切换四级内容：课程、章节、小节、知识点。
- [x] 用不同颜色和边界效果区分章节与小节区域。
- [x] 点击章节、小节或知识点后，显示对应名称和简要关系信息。
- [x] 提供微调模式，可调整球面边界点，并同步更新关联区域。
- [x] 支持导入旧版和新版 JSON 配置，并导出规范化配置。
- [x] 支持新增、修改和删除课程、章节、小节、知识点及共享顶点。
- [x] 支持通过选取已有顶点或点击球面新建章/节边界。
- [x] 支持边界顶点插入、排序和解除引用。
- [x] 支持撤销、重做、未导出提示和离开页面保护。

## 3. 数据要求

- [x] 课程数据包含课程、章节、小节、知识点、顶点和边界关系。
- [x] 支持将 Excel 中的课程路径和球面坐标生成前端可读的 JSON 数据。
- [x] 章节和小节的球面边界至少包含 3 个有效顶点。
- [x] 导入时检查重复 ID、无效坐标、缺失的父章节和无效顶点引用。
- [x] 导出时移除 Three.js 运行时缓存和演示占位数据。

## 4. 验收标准

- [x] 四门示例课程可正常展示和切换。
- [x] 旋转、缩放、点击和四级内容切换正常。
- [x] 章节、小节区域及文字标签显示清晰。
- [x] 微调边界点后，相关区域能正确重新生成。
- [x] 页面在桌面端和移动端均可基本使用。
- [x] schema v3 示例配置可升级并导出为 schema v4。
- [x] 空课程可以建立，非法边界会被拒绝导入或导出。
