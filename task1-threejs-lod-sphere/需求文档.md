# 课程球面知识地图需求文档

## 1. 项目目标

将数学课程的“课程—章节—小节—知识点”结构展示在可交互的三维球面上，让用户能从整体到局部逐级查看课程内容。

## 2. 核心功能

- [ ] 展示高等数学上、高等数学下、线性代数、概率论与数理统计四门课程。
- [ ] 支持点击课程进入单球查看，并可返回课程总览。
- [ ] 支持拖拽旋转和缩放球体。
- [ ] 根据缩放距离自动切换四级内容：课程、章节、小节、知识点。
- [ ] 用不同颜色和边界效果区分章节与小节区域。
- [ ] 点击章节、小节或知识点后，显示对应名称和简要关系信息。
- [ ] 提供微调模式，可调整球面边界点，并同步更新关联区域。

## 3. 数据要求

- [ ] 课程数据包含课程、章节、小节、顶点和边界关系。
- [ ] 支持将 Excel 中的课程路径和球面坐标生成前端可读的 JSON 数据。
- [ ] 章节和小节的球面边界至少包含 3 个有效顶点。

## 4. 验收标准

- [ ] 四门课程可正常展示和切换。
- [ ] 旋转、缩放、点击和四级内容切换正常。
- [ ] 章节、小节区域及文字标签显示清晰。
- [ ] 微调边界点后，相关区域能正确重新生成。
- [ ] 页面在桌面端和移动端均可基本使用。
