# 任务一：Three.js 球面知识地图编辑器

## 运行

不要直接双击 `index.html`；这个页面使用 Three.js ES module 和 JSON import，需要通过本地 Vite 服务访问。

```powershell
npm install
npm run dev
```

打开本地地址：`http://127.0.0.1:5173`

也可以直接聚焦某一门课，例如：

```text
http://127.0.0.1:5173/?course=gaoshu-xia
```

生产构建：

```powershell
npm run build
```

配置模型检查：

```powershell
npm run check:config
```

## 已包含功能

- 四个教材球：高等数学上、高等数学下、线性代数、概率论与数理统计。
- 支持导入 schema v3/v4 JSON 配置，并导出清理后的 schema v4 配置。
- 左侧内容树支持选择课程、章节、小节和知识点；右侧属性面板支持修改名称、说明、颜色和坐标。
- 支持新建、删除课程、章节、小节、知识点和可复用球面顶点。
- 新建章节/小节时，可依次选择已有顶点或直接点击球面创建顶点并闭合边界。
- 章节和小节边界支持插入顶点、调整顶点顺序以及解除顶点引用。
- 删除共享顶点时会检查全部区域引用；如果会造成边界不足三个点，则拒绝删除。
- 支持撤销/重做、未导出状态提示、离开页面保护和 `Ctrl/Cmd+S` 快速导出。
- 总览 LOD0：只显示球体和外层端点。
- 点击教材球或右侧按钮后聚焦单球。
- 拉近/拉远自动切换四级 LOD：教材、章节、小节、知识点。
- 每门课只渲染一个不透明球面；章节色、小节色和凹槽由 Shader 内的语义场控制，不再叠加区域网格。
- 章、节使用独立边界距离场；小节层级仍保留更宽、更深、更暗的章节边界。
- 章节/小节文字采用统一目标字号，仅在极小区域内有限缩放，并以局部弯曲网格贴近球面。
- 小节区域严格限制在所属章节内；无直属小节的“新手村”按与之相交的四个入门小节划分。凹区域使用有向球面面积判定内外侧；重叠区域按最近区域中心稳定归属，未落入任何边界的空白区域保留球面底色。
- OrbitControls 支持拖拽旋转、缩放。
- 微调模式支持选中共享交点后改 `phi/psi`、方向按钮微调，也支持按住 Shift 在球面上拖动；关联边界同步变化，松手后重建语义场。
- 未被任何章/节边界引用的辅助点不会显示为外层点或编辑控制点。
- LOD3 保留小节名并显示球面知识点，同时隐藏外层代表点；没有独立知识点数据的内置小节会显示仅用于运行时展示的 K1/K2/K3。

## 编辑流程

### 导入和导出

1. 点击左上角“导入”，选择已有的 JSON 配置。
2. 编辑器会验证课程层级、顶点坐标和边界引用；错误会指出对应的数据路径。
3. 点击“导出”或按 `Ctrl/Cmd+S` 下载当前配置。

编辑器内部会生成 `__layout`、`__color` 等渲染缓存，导出时会自动移除这些字段。旧版自动生成的 `K1/K2/K3` 占位知识点也不会进入导出结果。

### 新建章节或小节

1. 在左侧选择课程，然后点击“＋新建章”；或者选择章节后点击“＋新建小节”。
2. 在底部放置栏填写名称。
3. 点击已有蓝色顶点可复用共享点；点击球面空白处可创建新顶点。
4. 选择至少三个不同顶点后点击“完成”。

小节的新建边界点必须位于所属章节内。

### 编辑点和边界

- 点击“微调”后可拖动蓝色顶点或知识点，也可使用 `phi/psi` 滑杆和方向按钮。
- 知识点的拖拽、滑杆微调和坐标输入都会限制在所属小节内，越界时停在小节边界内。
- 选中章节或小节后，可选择“＋单区域边界点”，新点只插入当前区域最近的边界线段。
- 选择“＋相邻共同点”后点击两个相邻区域的共同边界线，新点会吸附到边界并同时加入两个区域。
- 属性面板中的边界列表支持前移、后移和从当前边界解除引用。
- “新建顶点”可以创建暂未被区域引用的共享顶点；此类顶点在微调模式下仍可选择。
- `Ctrl/Cmd+Z` 撤销，`Ctrl/Cmd+Shift+Z` 或 `Ctrl/Cmd+Y` 重做，`Esc` 取消当前放置。

## 数据

- `src/data/course-data.json`：前端内置的 schema v3 示例数据，载入后会在内存中规范化为 schema v4。
- `course-config.template.json`：可直接导入编辑器的 schema v4 单课程模板，包含 4 章、12 节和 24 个知识点。
- `course-config.schema.json`：导出配置的 JSON Schema，可用于编辑器提示或外部数据校验。
- `src/config-model.js`：配置清理、兼容升级、引用校验和序列化。
- `scripts/generate_course_data.py`：读取 XLSX 中的节路径、球面坐标、点对和章范围，生成共享顶点 ID 数据。
- `scripts/generate_template_config.mjs`：重新生成课程模板及球面坐标。
- `scripts/check_template_config.mjs`：检查模板结构、唯一 ID、球面坐标、区域包含关系及异常配置。
- `src/data/*.xlsx`：章、节和交点坐标的主要数据源。
- `src/data/*.py`：保留的参考曲线脚本；目前仅用于补齐线性代数表格缺失的 `P34`。

重新生成课程 JSON：

```powershell
python -m pip install -r requirements.txt
python scripts\generate_course_data.py
```

重新生成并测试模板配置：

```powershell
npm run generate:template
npm test
```
